# Гайд для художников: ассеты и катсцены (PS1/PS2-стиль)

## Общие правила
- Масштаб: **1 единица = 1 метр**. Дверной проём ~1×2.1 м, высота персонажа ~1.7 м.
- Имена файлов: латиница, snake_case (`old_door.glb`, `stranger_portrait.png`).
- Куда класть файлы в проекте:
  - 3D-модели → `assets/models/`
  - текстуры → `assets/textures/`
  - портреты для диалогов → `assets/portraits/`
  - полноэкранные 2D-иллюстрации → `assets/art2d/`
- Просто скопируйте файл в папку — Godot импортирует его автоматически при следующем открытии редактора.

## 3D-художнику

### Бюджеты (PS1/PS2-стиль)
| Тип | Треугольники | Текстура |
|---|---|---|
| Мелкий проп (бутылка, книга) | 20–150 | 32–64 px |
| Крупный проп (мебель, дверь) | 150–500 | 64–128 px |
| Персонаж | 400–1200 | 128–256 px |
| Модульный кусок локации (стена, пол) | до 200 | 64–128 px |

### Стиль текстур
- Низкое разрешение, рисованные/фотографические, **без normal map и PBR** — только albedo.
- Затенение запекайте в текстуру или вертексные цвета (vertex paint в Blender поддерживается glTF и виден в Godot).
- Лучше один атлас на объект/персонажа, чем много мелких текстур.

### Экспорт из Blender
1. Apply transforms (Ctrl+A → All Transforms), origin по низу объекта.
2. File → Export → **glTF 2.0 (.glb)**. В настройках: +Y Up (по умолчанию), Apply Modifiers ✓, если есть анимации — Animation ✓.
3. Коллизии бесплатно через суффиксы имён мешей в Blender:
   - `имя-col` — видимый меш + точная коллизия по нему;
   - `имя-colonly` — невидимый меш, только коллизия (так делайте упрощённые коллизии для сложных объектов);
   - `имя-convcol` — выпуклая коллизия (для подвижных объектов).
4. Один .glb = один объект/персонаж. Локации — модульными кусками.

### Анимации персонажей
- В Blender каждая анимация — отдельный Action (`idle`, `walk`, `attack`, `cutscene_wave`...). Перед экспортом — Push Down в NLA.
- В Godot .glb откроется с готовым `AnimationPlayer`, анимации доступны по этим именам.

### Подключение в Godot (может сделать и художник)
1. Перетащить .glb из FileSystem в сцену уровня.
2. PS1-материал: на меше → Surface Material Override → New **ShaderMaterial** → Shader = `shaders/psx_lit.gdshader` → в параметрах указать текстуру (`albedo_tex`). Это даст «дрожание» вершин и аффинные текстуры как на PS1.
   - Альтернатива без шейдера: StandardMaterial3D → Sampling → Filter = **Nearest**, Roughness = 1.
3. Сделать объект интерактивным (осмотр по E): правой кнопкой по корню объекта → Change Type → **StaticBody3D**, добавить дочерний CollisionShape3D (или использовать -col из Blender), прикрепить скрипт `scripts/examine_item.gd`, в инспекторе заполнить `Item Name`, `Description`, `Prompt Text`. Всё, подсказка и окно осмотра заработают сами.
   - Для диалога вместо этого прикрепить `scripts/dialogue_trigger.gd` и указать JSON и ключ (см. ниже).

## 2D-художнику

### Портреты для диалогов
- PNG с прозрачным фоном, **256×256** (в кадре — по грудь, лицом к центру экрана).
- Положить в `assets/portraits/`, путь указывается в JSON диалога (поле `portrait`).

### Полноэкранные иллюстрации (2D-катсцены и ключевые сцены)
- PNG **1280×720**. Для пиксельного стиля можно 320×180 или 640×360 — движок растянет без мыла (фильтрация Nearest включена в проекте).
- Положить в `assets/art2d/`, путь указывается в JSON (поле `image`).
- Иллюстрация остаётся на экране, пока в следующей реплике не появится новая `image` или диалог не закончится.

## Катсцены

### 2D-катсцена (иллюстрации + текст) — без программиста
1. Открыть/создать JSON в `dialogues/`, добавить свой ключ:
```json
"intro_cutscene": [
  {"image": "res://assets/art2d/rain_street.png", "text": "Той ночью шёл дождь."},
  {"image": "res://assets/art2d/window.png", "name": "Голос", "text": "...и кто-то стоял у окна."},
  {"name": "Я", "text": "Мне нужно войти.", "portrait": "res://assets/portraits/hero.png"}
]
```
2. Запуск: любой объект со скриптом `dialogue_trigger.gd` (указать файл и ключ `intro_cutscene`), либо из кода:
   `DialogueManager.start_from_file("res://dialogues/мой.json", "intro_cutscene")`.
3. Игрок на время сцены блокируется автоматически, текст листается на E/клик.

### 3D-катсцена (камера и персонажи в мире)
1. В сцене уровня добавить: `Camera3D` (камера катсцены), `AnimationPlayer`, `Node` со скриптом `scripts/cutscene_3d.gd`.
2. В инспекторе Cutscene3D назначить `Animation Player`, `Cutscene Camera`, имя анимации.
3. В AnimationPlayer создать анимацию: ключи позиции/поворота камеры, проигрывание анимаций персонажей; в нужный момент — дорожка **Call Method** на DialogueManager → `start_from_file` (реплики поверх 3D).
4. Запуск: вызвать `play()` — из сигнала `interacted` любого Interactable, из кода, или поставить Cutscene3D ребёнком Area3D и включить `Auto Play On Area` (сработает, когда игрок войдёт в зону).
5. Cutscene3D сам блокирует игрока, переключает камеру и возвращает всё обратно.

### Чеклист встраивания ассета
1. Файл лежит в правильной папке `assets/...`, имя — snake_case латиницей.
2. Масштаб/размер соответствует таблице бюджетов.
3. Текстуры с фильтром Nearest или PSX-шейдер.
4. У интерактивных объектов есть коллизия (иначе луч взаимодействия их не увидит).
5. Запустить игру (F5) и проверить на тестовом уровне.
