# Horror Template — техническая база (Godot 4 / GDScript)

Шаблон инди-хоррора: low-poly PS1/PS2-эстетика, 3D-мир + 2D-диалоги и катсцены поверх.

## Запуск
1. Установить **Godot 4.3+** (стандартная версия, не .NET): https://godotengine.org/download
2. Godot → Import → выбрать папку с `project.godot` → Open → F5.

## Управление (по умолчанию, переназначается в настройках)
WASD — движение, мышь — обзор, **E** — взаимодействие, Shift — бег, Ctrl — присед, F — фонарик, Esc — пауза.

## Что уже работает
- Главное меню: Продолжить / Новая игра / Загрузить / Настройки / Выход.
- Настройки: чувствительность мыши, инверсия Y, громкость, полный экран, **переназначение клавиш**. Хранятся в `user://settings.cfg`.
- Сохранения: 3 слота (`user://save_slot_N.json`) — сцена, позиция игрока, сюжетные флаги. Сохранение из меню паузы.
- Контроллер от первого лица с приседом, бегом, фонариком и покачиванием камеры.
- Взаимодействие на E: луч из камеры + подсказка `[E] Осмотреть` (клавиша в подсказке обновляется при ребинде).
- 2D-диалоги поверх 3D: имена, портреты, «печатающийся» текст, полноэкранные иллюстрации для катсцен. Источник — JSON (`dialogues/`).
- Переходы между сценами с затемнением (SceneLoader).
- PSX-шейдер (`shaders/psx_lit.gdshader`): дрожание вершин + аффинные текстуры.

## Структура
```
autoload/      Settings, SaveManager, SceneLoader, DialogueManager (глобальные системы)
scenes/
  main_menu/   главное меню
  player/      контроллер игрока + HUD
  ui/          настройки, пауза
  levels/      уровни (test_level.tscn — пример)
scripts/       Interactable, ExamineItem, DialogueTrigger, LevelDoor, Cutscene3D
dialogues/     JSON-файлы диалогов
shaders/       PSX-шейдер
assets/        models / textures / portraits / art2d / audio (сюда кладут работу художники)
docs/          ARTISTS_GUIDE.md — гайд для художников
```

## Как добавлять контент (кратко)
- **Новый уровень**: дублировать `test_level.tscn`, не забыть инстанс `player.tscn`. Переход — объект со скриптом `level_door.gd`.
- **Осматриваемый предмет**: StaticBody3D + CollisionShape3D + скрипт `examine_item.gd`, текст в инспекторе.
- **NPC/диалог**: то же со скриптом `dialogue_trigger.gd`, диалог — в JSON в `dialogues/`.
- **Сюжетные флаги**: `SaveManager.flags["имя"] = true` — попадают в сейв автоматически.
- Подробно для художников: `docs/ARTISTS_GUIDE.md`.
